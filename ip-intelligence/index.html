IP Intelligence for JavaScript

51Degrees IP Intelligence

Find out where an IP address is, and who owns the network it's on. 51Degrees IP Intelligence looks the address up in the 51Degrees cloud service and sends back the answer.

Call the cloud service from the browser, as this page does, or from Node.js with the fiftyone.ipintelligence package. A free Resource Key returns the country and how confident the cloud service is about the location. A paid plan adds the region, the town, the latitude and longitude, and the network's registered owner. This page's key is on a paid plan, so the playground shows them all.

Country for free

Paid plans add the region, town, latitude and longitude, the network's registered owner, and more. See them all in the property dictionary.

Cloud or your own servers

The Node.js packages use the cloud service, or an IP Intelligence data file on your own servers, with almost all the same properties.

Getting started

  1. Create a Resource Key. The link opens with the properties on this page ticked. The country and location confidence are free, and the others need a paid plan.
  2. Install the package. 
    npm install fiftyone.ipintelligence
  3. Look up an address. 
    const IpIntelligencePipelineBuilder =
  require('fiftyone.ipintelligence').IpIntelligencePipelineBuilder;

const pipeline = new IpIntelligencePipelineBuilder({
  resourceKey: 'your-resource-key'
}).build();

const flowData = pipeline.createFlowData();
flowData.evidence.add('query.client-ip', '81.2.69.142');
flowData.process().then(function () {
  console.log(flowData.ip.country.value);
});
  4. See the IP Intelligence quick start for the on-premise data file and more examples.
