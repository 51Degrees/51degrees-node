51Degrees Human Confidence

How likely is it that a person is looking at your page? Human Confidence answers High, Medium, or Low for each visit, straight from the 51Degrees cloud service.

Add the 51Degrees script to your page and read the value in the browser, for your analytics. Or ask the cloud service from your Node.js server and decide what each visit gets before you send the page. Human Confidence needs the Pro plan.

What the values mean

Value Meaning What websites usually do
High High confidence that a person is reading the page. Let the request through.
Medium Mixed signals. Could be a person, could be a script. Serve the page, or challenge with a CAPTCHA or a sign-in first.
Low Almost certainly no person is reading it. Refuse the request, or serve a version of the page made for machines.
Unknown Not measured, usually because the script didn't run. Treat it as Medium.

Getting started

  1. Create a Resource Key from this link. It opens with the properties Human Confidence needs already ticked. Add the License Key from your Pro plan and create the key.
  2. Add the script to a page, with your Resource Key in place of YOUR_RESOURCE_KEY, and read the value once the script has finished. 
    <script src="https://cloud.51degrees.com/api/v4/YOUR_RESOURCE_KEY.js"></script>
<script>
  fod.complete(function (data) {
    console.log(data.derived.humanconfidence);
  });
</script>
  3. To decide on your server what each visit gets, follow Deploy Human Confidence with the cloud, which has the Node.js, PHP, and Python code.
